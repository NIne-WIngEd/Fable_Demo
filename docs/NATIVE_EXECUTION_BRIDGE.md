# FloRA native execution bridge

FloRA can now orchestrate an explicitly supplied, independently qualified native worker without running its synchronous inference adapter in the async runner. **No personality model, MFM, substitute judgment model or deployment factory is supplied by this milestone.**

## Implemented boundary

- **Freeze the task.** `FrozenNativeArmPlan` records one exact invocation and context plan/hash for each case and phase. Its hash belongs to the frozen paired-run binding. The adapter checks the exact host, authority namespace, question, history, phase-specific model binding and private context bytes before dispatch.
- **Qualify the actual code.** The worker manifest pins the executable, factory, codec, read-service and meter configurations. An independently enrolled verifier must qualify the supplied factory and its transitive executable dependencies. Hashing bytes alone grants no qualification.
- **Keep inference terminable.** `QualifiedNativeProcessWorker` launches a Linux process without a shell or inherited environment. It copies the opened executable/factory into sealed descriptors, bounds private stdin/stdout/stderr, discards stderr, and terminates the process group on cancellation, deadline or output limits. Startup cancellation cannot hide a newly spawned process. The qualified factory must not escape that process group; this transport is not an operating-system sandbox.
- **Read the actual selected services.** `SelectedNativeReadServices` assembles actual runtime context, recovers an existing native judgment and verifies actual phase lineage. It checks independent phase permission and gates original source closure before opening context plaintext. Each operation owns a fresh initialized read session. Selected SQL uses a narrow single-`SELECT` guard; DDL, transactions and reconciliation are denied. Cancellation keeps the read slot occupied until its thread finishes and closes its connections.
- **Open the frozen phase on that connection.** Each invocation identifies its exact immutable run, snapshot and arm. Anchored V2 entries also bind the earlier preregistration SHA, observed snapshot SHA and canonical capture event ID/SHA. The session's qualified `phase_route_for(entry, request, artifact_permissions)` resolver must return the actual `SelectedPhaseRoute`, with its runtime and lineage together and its custody on the same owned connection. Exact case, phase, arm, original history, context plan/hash/receipt and captured references must match. Current metadata-only custody authorization guards every inner private read; it does not recursively recover the full archive. `allow_current_fixture_route` defaults to false and is explicitly enabled only for mechanical current-head fixtures.
- **Keep control artifacts out of model context.** The actual phase-history controller receives a separate original permission-policy copy on the same owned connection. The model-context policy, state and episode views are copied before their original-only gate is installed, so shared final-seal/archive controllers retain their own current original predicates. This prevents recursive history checks and avoids denying legitimate control-custody authorization through a model-context filter. The resolver receives another current policy copy for exact authenticated artifact-and-ancestor reads. Comparison results, provider captures, phase archives and experiment manifests remain excluded from generic model context.
- **Require the actual observed final seal.** Actual selected custody detects a durable preregistration even if a caller omits its optional final-authority object or presents an older plan. A committed anchor without its immutable index also blocks evaluation. Direct preparation and execution require the actual registered final binding and exact native invocation/header. Current inner seal checks follow slow qualification and precede private reads, dispatch and each selected write. Full outer producer/capture qualification runs on an owned passive session immediately before worker dispatch and before accepting a result, under the existing deadline. Fictional custody requires explicit `allow_unregistered_fixture_run`; that flag is rejected with actual selected custody and cannot authorize an anchored plan.
- **Bound the actual writer too.** Preflight final-seal metadata is read on an owned passive connection under the task deadline. Actual selected registration requires `NativeWriterGuard` over the same exclusively owned Linux psycopg connection used by custody. Its source and static configuration hashes are an all-or-none part of the worker manifest; absent fields preserve the legacy manifest hash. An independently verified owner receipt must cover the actual connection and factory's exclusive-use contract. A retained duplicate socket interrupts a blocked PGconn operation at the smaller of its frozen allowance and remaining task time. The driver stays on its owner thread. Timeout, cancellation or operation failure poisons the connection; failed retirement cannot reopen its owner reservation. This watchdog bounds that PGconn, not Kurrent, object-store or producer callbacks.
- **Bound passive callbacks too.** Each worker and native adapter has its own `OwnedPassiveReads` pool. Qualification, sealed-code copying, encoding, decoding and metering acquire a slot before submitting a callback. Cancelling its await cannot free the slot while the physical callback runs or accumulate a queue of executor threads. One frozen invocation includes its encoder/preflight, so cancelling that stage cannot reopen the same task. A pool cannot move between event loops.
- **Avoid repeating the same initial lineage proof.** A freshly constructed production route already authenticated its exact frozen context and producer/phase proof. Recovery retains the exact request/question/context checks, current private-read gates and runtime qualification/assembly, then verifies the full phase/producer proof afterward. It does not repeat an identical pre-recovery lineage assembly; fixture fallback retains that check. No permission result is cached and the production deadline is unchanged.
- **Recover without writing.** Passive recovery calls the runtime and native lineage with `reconcile=False`. Existing exact private step/raw-reference registration is required. A missing index is unavailable to this read path; it cannot repair the index after its await was cancelled.
- **Keep proof and usage exact.** Completion must name the exact invocation, request hash and qualified output event. The independent meter must bind the actual worker observation, runtime input/output and receipt. Verified usage survives later refusals or rejected results; absent or invalid proof leaves usage unknown.
- **Register after fresh authority.** The adapter rechecks current phase permission before each selected custody write and before retaining an accepted execution record. Interrupted registration may leave provisional receipts. It cannot create a successful run without the separate current `save_run` verification.

## Explicit deployment inputs

The model-producing workstreams must supply the real checkpoint, runtime factory, producer input/output codec, execution proof adapter, artifact qualification, phase/export proof and actual meter. A common evaluable response contract must be agreed before comparing native structured output to a language-model answer. Fictional receipt fixtures are not that response contract.

`InitializedNativeSessionFactory` takes an explicit connection opener and an initialized-service binder. The opener receives the frozen backend read timeout and must enforce the real driver/server and network deadlines. The binder receives the guarded connection and may bind only existing selected tables and artifacts. It must not initialize schema, grant permissions, infer or repair indexes. Actual opener/binder code, backend addresses, credentials, connection ownership and transitive callbacks require independent deployment qualification. None is inferred from the environment.

Cancelling an async database or passive callback await cannot kill a Python thread. Concurrency is bounded, expired work owns no inference/write continuation, and qualified backend/codec/proof deadlines must finish the remaining callback. A claimed timeout configuration alone is not evidence that physical backend faults terminate on time. Passive private receipt reads also reauthorize immediately before each inner object lookup/decryption; a phase check before a slow metadata fetch cannot authorize a later private read.

The native adapter can dispatch `same_evidence_ablation` only when every invocation has the exact arm-bound immutable archive and the reader uses the production selected-route path. The after archive must carry the actual producer's independently qualified update-exclusion execution proof, checked before dispatch and throughout recovery. A fixture-only reader or missing archive leaves the arm unavailable; a missing or invalid producer proof refuses its route. Giving another general model the same context would not isolate the personal judgment update.

The two-stage route freezes the design first, captures actual before and after authority under that preregistration, and derives the final paired plan afterward. V2 headers can include observed body/event hashes because the capture does not contain the later final run SHA. The earlier V1 final-plan snapshot route remains a legacy mechanical path. A snapshot cannot be recaptured under either identity. Historical producer bindings and update-exclusion proof still require actual independent qualification, while source and evaluation consent remain current. The reader chooses the arm from the exact archive binding; availability of the infrastructure does not supply a real producer, checkpoint or proof.

An anchored session binder must supply an actual `RegisteredExperimentFinalBinding` on its owned selected connection. `final.bind_read_connection(connection, phase_custody=..., historical_bindings_by_snapshot=...)` supports this with explicit initialized phase services and complete actual producer ports. It does not guess or clone external model code. Omitting those ports yields only a metadata guard, which cannot pass full outer evaluation qualification. All nested source authorities, phase/runtime planes and artifact permission readers must belong to the owned session; separately located authority databases need explicit owned readers.

An actual selected writer requires the explicit exclusive-owner verifier and receipt, exact psycopg version and a frozen `NativeWriterConfiguration`. Hashes alone do not establish exclusive connection ownership. The same actual controller and PGconn are retained during each fenced write. Qualified deployment callbacks must separately enforce their Kurrent/object/producer deadlines; a SQL watchdog does not make an arbitrary synchronous callback cancellable. Interrupted canonical work remains provisional for explicit reconciliation.

## Validation and limits

- Ten real subprocess lifecycle tests cover private pipes, exact sealed code, qualification changes, false dispatch authorization, finite deadlines, environment isolation, output/stderr caps, cancellation, and process-group cleanup. One further physical callback test verifies that repeated cancellation cannot release a running callback's slot or submit more threads.
- Ten native adapter contract tests and eighteen concrete reader tests use the actual runtime/lineage classes with supplied fictional outputs and signed fictional proofs. They cover frozen inputs, strict recovery, invalid proof, current revocation, registration order, bounded reader ownership, phase denial before ciphertext fetch, phase withdrawal during private receipt metadata fetch, and cancellation without later writes or reopening a sealed task. Production-route cases additionally reject absent archives/resolvers, plain current-runtime substitutes, mismatched archive/run/arm/context/history, withdrawal during routed private recovery, changed question/context rejection before archive plaintext, and withdrawal after a qualified constructor before recovery. The actual selected-history-controller regression uses current typed fixture grants and withdrawal, verifying independent policy copies without a frozen-history substitute. Shared original-controller policy/state objects remain unmodified by the model gate. A cancelled live reader retains its slot, while actual closure wakes its waiter without waiting for the long component timeout. No-open assertions instrument the physical shared object backend rather than an instance method bypassed by guarded reads.
- Eleven anchored native boundary tests cover canonical all-or-none V2 references, mixed-header rejection, explicit fixture boundaries, actual durable anchor detection and canonical orphan refusal, an omitted final authority before private preparation, an anchor appearing during slow qualification, and denial of owned original plaintext before the actual final seal. A stalled current-metadata read also verifies task timeout with a responsive event loop and no later registration. Their row/model bytes are fictional and they do not certify full producer qualification or actual backend performance.
- Eleven writer contract tests cover a physically stalled socket, retained actual driver identity, owner-thread closure, task deadline caps, refusal after changed proof/configuration, overlapping owners, poisoned retirement, failed watchdog setup with a raising driver close, and complete manifest hashes with unchanged legacy records. Socket-driver and owner proofs are explicitly fictional.
- `test_selected_native_comparison.py` now uses the actual `NativeArmAdapter`, fresh bounded selected readers, real XTDB/Kurrent custody and the same guarded writer connection. Worker outputs and owner/meter qualifications are fictional transport fixtures. `test_selected_native_writer_faults.py` separately blackholes a real psycopg response and checks physical owner-side retirement with no late SQL continuation. These physical gates need selected-engine CI; compilation alone does not certify them. The paired protocol remains sixty seconds.
- `test_selected_native_read_sessions.py` exercises fresh guarded sessions over the actual selected backend fabric, existing custody, an actual immutable phase archive and live revocation. It must pass the selected-engine CI gate before being called backend-qualified. It does not fault-test deployment driver deadlines or certify model behavior. Current-head mechanical fixtures allow fifteen seconds per passive read and paired component task; archived mechanical fixtures allow thirty seconds per passive read. Dedicated subprocess timeout and cancellation cases retain their short enforced deadlines. These are test allowances, not response-latency results. The paired production protocol budget is unchanged.

This milestone establishes execution and custody mechanics. It demonstrates no learned judgment, personality fidelity, MFM quality, actual inference latency, FloRA superiority or completed Part 1 experiment.
